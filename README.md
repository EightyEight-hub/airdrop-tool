# Airmail (ARML)

A fixed-supply ERC-20 token on Base, distributed free to active Base wallets.

- Contract: `0x9EF12bBC2Cd366ae6817fD49CA512c8c672Db79a`
- Network: Base
- Total supply: 21,000,000 (18 decimals), no mint function
- Tax: 0%
- Pool: ARML / WETH on Aerodrome
- Chart: https://dexscreener.com/base/0x72d0934b0a247fa6c6e6dbec9b8fd58acd1f97aa

No blacklist, no maximum wallet, no cooldown, no pause. Transfers are unrestricted.
The contract source is verified on Basescan.

This repository also holds the single-file tool used to deploy the token and
run the airdrop.
